Privacy Policy

FloLabs Highlight Cutter · operated by FloLabs Innovations Group · last updated October 23, 2026

FloLabs Highlight Cutter is an internal tool used by FloLabs Innovations Group to trim recordings of its own meetings and publish them to the FloLabs YouTube channel. Access is limited to FloLabs team members with a password.

What the tool processes

  • Meeting recordings and their transcripts that a team member uploads.
  • The trimmed video and the list of cuts the tool produces.

How it is used

  • Transcript text is sent to Anthropic's Claude API, which decides which parts of the meeting to keep.
  • When a team member chooses to publish, the trimmed video, and any short clips of it that team member selects, are uploaded to the FloLabs YouTube channel using the YouTube API Services, with the title, description and visibility that team member chose.

YouTube API Services

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

The tool only requests permission to upload videos to, and read the name of, the connected FloLabs channel. It stores one access token for that channel on the FloLabs server, readable only by the tool. Access can be revoked at any time from the Google account's third-party connections page, or with "Disconnect" in the tool.

Storage and deletion

  • Recordings, transcripts and trimmed videos are stored on FloLabs' own server (Amazon Web Services, Frankfurt).
  • They are deleted from the server once the video and its short clips have been uploaded to YouTube, and in any case within 3 days.
  • No data is sold or shared with anyone other than the services named above.
